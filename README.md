# 長庚醫療島 (Chang Gung Medical Archipelago)
### 🏥 3D 微縮玩具模型即時互動醫療城市 · Toy Diorama Medical City

> 🌐 **線上體驗網址**：[https://winfred0505.github.io/cgmh-medical-island/](https://winfred0505.github.io/cgmh-medical-island/)

---

## 📖 專案簡介

「長庚醫療島」以台灣醫療網絡先鋒——**長庚醫療財團法人全球資訊網 (CGMH)** 的全台分院、特色專科、癌症卓越與長照機構為核心藍本，參考台灣知名創新專案「政策島」的六角形空間拓撲與微縮玩具模型設計架構，打造出具有溫暖陶土與微縮積木質感的 3D 互動城市。

使用者可以在由 10 座六角島嶼構成的醫療群島中自由巡航，觀看即時急診擁擠度燈號、門診叫號進度，以及在各島拱橋間穿梭的微型救護車、院際巡迴接駁專車與空中急救無人機。

## 🌟 核心特色

### 1. 10 座標誌性六角醫療島嶼
* **01 林口長庚總院島**：全台最大醫學中心，配備雙塔醫療大樓、質子治療加速器旋轉光環、急救停機坪與旋翼直升機。
* **02 台北長庚都會島**：都會核心精緻醫療、婦幼健康與試管嬰兒生殖醫學權威。
* **03 基隆長庚情人湖島**：山海相依的情人湖癌症卓越中心與微縮海港旋轉燈塔。
* **04 桃園長庚中醫運動島**：中醫藥臨床中心（中式傳統飛簷樓閣）、顱顏整形修復與運動醫學水療池。
* **05 長庚養生文化村島**：全台高齡樂齡示範園區，中央活動圓頂、彩色木屋別墅與微型風車。
* **06 高雄長庚港都醫學島**：陳肇隆院士活體換肝世界先驅大樓、南部質子中心與兒童醫療大樓。
* **07 嘉義長庚南院島**：嘉南平原大跨度現代綠建築、阿里山 5G 智慧遠距通訊天線。
* **08 雲林長庚海線長照島**：麥寮沿海巡迴醫療車隊、長照機構與風力發電機。
* **09 長庚智慧醫療與生醫研發島**：AI 算力立方體、全向動態光環與衛星通訊雷達碟。
* **10 全人社服與公益守護島**：長庚愛心服務大廳、身障口足畫家戶外展區。

### 2. 即時醫療動態與急診雷達
* **全院急診雷達 (ER Radar)**：一鍵展開全台各院區即時等候看診人數、等待住院人數、加護病房待床與狀態燈號（正常/忙碌/警戒）。
* **即時數據動態模擬**：系統模擬真實醫院脈搏，每 8 秒微幅更新門診人次與急診動態。
* **院區詳細資訊抽屜**：點擊任一小島，相機平滑平移聚焦（Lerp），滑出即時指標、4 大核心技術柱及官方掛號深層連結。

### 3. 微縮動態交通系統
* **微型救護車**：頂部配備交替閃爍的紅藍警示燈，在主要醫學中心環島路徑巡航。
* **長庚經典綠白院際接駁專車**：穿梭於島際拱橋，提供雙院通勤意象。
* **空中器官運送無人機**：沿著跨院醫療協作光弧線（Quadratic Bezier Curve）巡邏。
* **微型醫護小公仔**：白袍醫師與粉紅護理師在林蔭環道漫步。

### 4. 晝夜晨昏光影系統
* 支援 **🌅 晨曦 (06:00)**、**☀️ 正午 (12:00)**、**🌇 黃昏 (18:00)** 與 **🌙 幽夜 (21:30)** 四段切換。
* 低多邊形棉花糖積木雲朵徐徐飄動，夜間模式下建築窗戶與醫療十字自動透出溫馨暖光。

## 🛠️ 技術架構

* **3D 算圖引擎**：Three.js (ESM Module via CDN) + OrbitControls
* **地形與數學拓撲**：尖頂六角形軸向座標系統 $(q, r) \to (x, z)$ 轉換、懸崖梯級擠出幾何
* **使用者介面**：HTML5 + 現代玻璃擬態 (Glassmorphism) CSS
* **音效合成**：Web Audio API 原生音頻合成技術（無外部音檔負擔）
* **無依賴部署**：純前端原生模組化開發，支援 GitHub Pages 零配置即時靜態託管

## 🚀 本地開發與運行

本專案無需任何建置工具或 npm install，只需任意靜態伺服器：

```bash
# 複製專案
git clone https://github.com/winfred0505/cgmh-medical-island.git
cd cgmh-medical-island

# 啟動本機伺服器
python -m http.server 8080
```
瀏覽器造訪 `http://localhost:8080` 即可開始體驗。
